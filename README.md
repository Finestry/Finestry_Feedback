# Finestry

🇬🇧 [English](#english) · 🇪🇸 [Español](#español)

## English

Finestry is a macOS app (14 Sonoma or later) that arranges your windows into exact layouts, with the same gap everywhere, and saves them as scenes you bring back with one shortcut.

🌐 **Website:** [finestry.app](https://finestry.app)

> This repository is only for **reporting bugs and suggesting improvements**. The app's source code is not here.

### Report a bug

1. First check [Issues](https://github.com/Finestry/Finestry_Feedback/issues) to see if someone has already reported it.
2. If not, open a new one: [New issue](https://github.com/Finestry/Finestry_Feedback/issues/new).
3. Include:
   - macOS version
   - Finestry version
   - Steps to reproduce it
   - What you expected to happen and what happened
   - Screenshots or a video, if you can

### Suggest an improvement

Open an issue starting with **[Idea]** and explain what you would like and how you would use it.

### Who answers

Finestry is a one-person project, so a reply may take a few days. Thanks for your patience.

## Español

Finestry es una app de macOS (14 Sonoma o posterior) que coloca tus ventanas en distribuciones exactas, con el mismo espacio entre todas, y las guarda como escenas que recuperas con un atajo.

🌐 **Web:** [finestry.app](https://finestry.app)

> Este repositorio es solo para **reportar errores y proponer mejoras**. El código de la app no está aquí.

### Reportar un error

1. Comprueba primero en [Issues](https://github.com/Finestry/Finestry_Feedback/issues) si alguien ya lo ha reportado.
2. Si no, abre uno nuevo: [Nuevo issue](https://github.com/Finestry/Finestry_Feedback/issues/new).
3. Incluye:
   - Versión de macOS
   - Versión de Finestry
   - Pasos para reproducirlo
   - Qué esperabas que pasara y qué pasó
   - Capturas o vídeo, si puedes

### Proponer una mejora

Abre un issue que empiece por **[Idea]** y explica qué te gustaría y para qué lo usarías.

### Quién responde

Finestry es un proyecto de una sola persona, así que una respuesta puede tardar unos días. Gracias por la paciencia.
